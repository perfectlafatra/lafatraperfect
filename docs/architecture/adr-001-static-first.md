# ADR-001 — Vitrine statique d'abord

Statut : accepté le 14 octobre 2026.

Le frontend doit rester complet avec `PORTFOLIO_API_ENABLED=false`. Le backend initial fournit une base technique vérifiable mais ne bloque ni la navigation, ni les contenus, ni le contact documentaire. Cette décision maintient la priorité P0 du livre technique tout en préparant P1.
