# ADR-003 — Configuration Spring en `.properties`

Statut : accepté le 14 octobre 2026.

Le prompt maître demande `application.properties`, `application-dev.properties` et `application-prod.properties`, alors que l'arborescence v1.2 nomme des fichiers YAML. La demande directe est retenue. Les responsabilités, profils et variables restent conformes au livre technique.
