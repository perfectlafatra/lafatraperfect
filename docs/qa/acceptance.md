# Recette

Un statut VERT exige une commande exécutée et une preuve observée. ORANGE signifie résultat partiel ou preuve insuffisante ; ROUGE signale un blocage ou une non-conformité de sécurité ; NON EXÉCUTÉ indique un test non lancé ou indisponible.

Les preuves locales expurgées sont indexées dans `qa/results/README.md`. Les fichiers susceptibles de contenir des données ou secrets restent ignorés par Git.
