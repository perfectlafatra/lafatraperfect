# Sécurité

Ne publiez jamais de secret, `.env`, dump SQL, cookie de session ou donnée personnelle dans une issue ou un commit. Signalez une vulnérabilité au propriétaire du dépôt par un canal privé vérifié.

Le portfolio public est statique et n'expose aucun compte administrateur, API, base SQL ou formulaire serveur. Les contenus sont édités par Git puis reconstruits par GitHub Actions. Ne jamais publier de secret, donnée client ou capture non autorisée.
